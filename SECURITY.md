# Security Policy

## Supported Versions

Repo Radar is currently maintained on the latest release.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅         |
| < 1.0   | ❌         |

## Reporting a Vulnerability

If you discover a security vulnerability in Repo Radar, please report it privately rather than opening a public issue.

Use GitHub's private vulnerability reporting feature for this repository if available.

Please include:

* A description of the vulnerability.
* Steps to reproduce it.
* The potential impact.
* Any suggested fix, if known.

Security reports will be reviewed as soon as reasonably possible. If the issue is confirmed, a fix will be prepared and released when appropriate.
